# 로드맵

서비스가 앞으로 어떻게 발전하고, 아키텍처가 어떻게 바뀔지에 대한 문서와 발표 자료를 모아둡니다.

## 구성

- [`vision.md`](vision.md) — 목표 방향과 배경 (왜 이 방향인지)
- [`target-architecture.md`](target-architecture.md) — 목표 아키텍처와 현재 대비 변경점
- [`outline.md`](outline.md) — 발표 목차 초안 (내용을 계속 작성 중인 원고)
- [`presentations/`](presentations/) — 완성된 발표 자료 (HTML 등 최종 산출물)

## 발표 자료 추가하기

`presentations/`에 날짜를 접두어로 붙여 저장합니다. 예: `2026-09-architecture-roadmap.html`
